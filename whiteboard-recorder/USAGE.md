# 📖 使用指南

## 快速开始

### 1. 安装依赖

```bash
cd whiteboard-recorder
npm install
```

### 2. 启动应用

```bash
npm run dev
```

浏览器会自动打开 `http://localhost:3000`

## 界面说明

### 顶部标题栏
- 显示应用名称和简介

### 控制面板
- **开始录制**: 点击开始录制白板内容
- **暂停**: 暂停当前录制
- **继续**: 恢复已暂停的录制
- **停止**: 结束录制并生成视频
- **下载视频**: 将录制的视频保存到本地
- **清除**: 删除当前录制内容

### 白板区域
- 使用 Excalidraw 提供的完整绘图功能
- 支持的工具：
  - ✏️ 手绘工具
  - 📐 矩形、圆形、菱形
  - ➡️ 箭头和连线
  - 📝 文本框
  - 🎨 颜色选择器
  - 🖼️ 图片插入

### 预览区域
- 录制完成后自动显示
- 可以直接播放录制的视频

## 使用场景

### 1. 在线教学
- 讲解知识点时录制白板讲解过程
- 制作教学视频

### 2. 会议记录
- 记录会议中的白板讨论内容
- 保存创意构思过程

### 3. 演示制作
- 创建产品演示视频
- 制作操作指南

### 4. 设计草图
- 记录设计思路演进过程
- 保存头脑风暴内容

## 技巧和建议

### 录制前
1. 确保使用支持的浏览器（推荐 Chrome 或 Firefox）
2. 调整白板到合适的缩放级别
3. 准备好要绘制的内容

### 录制中
1. 保持绘制流畅，避免频繁修改
2. 可以使用暂停功能整理思路
3. 注意录制时长，避免文件过大

### 录制后
1. 预览检查录制内容是否完整
2. 及时下载保存录制文件
3. 如需重新录制，点击清除按钮

## 视频格式说明

### 录制格式
- **容器**: WebM
- **视频编码**: VP9 (优先) / VP8 (降级)
- **帧率**: 30 FPS
- **比特率**: 2.5 Mbps

### 格式转换

如需转换为 MP4 格式，可使用 FFmpeg：

```bash
ffmpeg -i whiteboard-recording.webm -c:v libx264 -preset slow -crf 22 output.mp4
```

### 视频压缩

如果文件过大，可以压缩：

```bash
ffmpeg -i whiteboard-recording.webm -c:v libvpx-vp9 -b:v 1M -c:a libopus compressed.webm
```

## 故障排除

### 问题：找不到 Canvas 元素

**症状**: 点击开始录制后显示错误"无法找到白板Canvas元素"

**解决方法**:
1. 等待页面完全加载后再点击录制
2. 刷新页面重试
3. 检查浏览器控制台是否有错误信息

### 问题：录制的视频是黑屏

**原因**: Canvas 未正确捕获

**解决方法**:
1. 确保白板区域可见
2. 在白板上绘制一些内容后再开始录制
3. 尝试使用不同的浏览器

### 问题：下载的视频无法播放

**原因**: 播放器不支持 WebM 格式

**解决方法**:
1. 使用 Chrome 浏览器直接播放
2. 安装 VLC 媒体播放器
3. 使用 FFmpeg 转换为 MP4 格式

### 问题：录制过程中浏览器卡顿

**原因**: 系统资源不足

**解决方法**:
1. 关闭其他占用资源的标签页或应用
2. 降低录制帧率（修改源码）
3. 降低白板复杂度

## 性能优化建议

### 1. 降低帧率
适用于不需要高流畅度的场景，可以将 30 FPS 降低到 15 或 24 FPS

### 2. 调整比特率
根据内容复杂度调整：
- 简单图形: 1-1.5 Mbps
- 中等复杂: 2-2.5 Mbps
- 高复杂度: 3-4 Mbps

### 3. 控制录制时长
建议单次录制不超过 10 分钟，长视频可分段录制后合并

## 进阶使用

### 自定义背景颜色

修改 `WhiteboardRecorder.jsx` 中的配置：

```javascript
initialData={{
  appState: {
    viewBackgroundColor: '#f0f0f0' // 修改为你想要的颜色
  }
}}
```

### 预设画布内容

```javascript
initialData={{
  elements: [
    {
      type: "rectangle",
      x: 100,
      y: 100,
      width: 200,
      height: 100,
      // ... 其他属性
    }
  ]
}}
```

## 最佳实践

1. **录制前准备**: 先在白板上做好基本布局，再开始录制
2. **分段录制**: 复杂内容分段录制，避免出错重来
3. **定期保存**: 录制完成后立即下载保存
4. **文件命名**: 使用有意义的文件名，方便后续管理
5. **备份重要录制**: 重要内容建议多次录制作为备份
