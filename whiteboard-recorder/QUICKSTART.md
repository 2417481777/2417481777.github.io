# ⚡ 快速启动指南

## 三步启动你的白板录制应用

### 步骤 1: 安装依赖

```bash
cd whiteboard-recorder
npm install
```

⏱️ 预计耗时: 2-3 分钟

### 步骤 2: 启动开发服务器

```bash
npm run dev
```

✅ 应用将自动在浏览器中打开 `http://localhost:3000`

### 步骤 3: 开始使用

1. 🎨 在白板上绘制内容
2. 🔴 点击「开始录制」按钮
3. ⏸️ 需要时可以暂停/继续
4. ⏹️ 点击「停止」完成录制
5. ⬇️ 点击「下载视频」保存

## 🎯 核心功能

| 功能 | 说明 |
|-----|-----|
| 🎨 白板绘制 | 使用 Excalidraw 的所有绘图工具 |
| 🎥 实时录制 | 30 FPS 高清录制 |
| ⏸️ 暂停/继续 | 灵活控制录制过程 |
| 💾 视频下载 | WebM 格式，高质量输出 |

## 🆘 遇到问题？

### 安装失败
```bash
# 清除缓存后重试
npm cache clean --force
npm install
```

### 端口被占用
```bash
# 使用不同端口启动
npm run dev -- --port 3001
```

### 录制无响应
- 等待页面完全加载
- 刷新页面重试
- 检查浏览器控制台错误信息
